RoomSheet

LiDARとApple RoomPlanを利用して室内を測定し、平面図、3Dモデル、 編集可能なSH3Dプロジェクトとして保存・書き出すためのアプリです。

RoomSheet uses LiDAR and Apple RoomPlan to capture rooms and export floor plans, 3D models, and editable SH3D projects.

About Requirements Support Privacy

About

RoomSheetは、RoomPlanで取得した室内データを端末内に保存し、 2D平面図、3Dモデル、SH3Dなどの形式で確認・書き出せます。 RoomSheetが書き出したパッケージは、別のRoomSheetへ読み込むこともできます。

RoomSheet stores RoomPlan captures on your device and lets you view or export them as 2D floor plans, 3D models, SH3D projects, and other RoomSheet package files. Packages exported by RoomSheet can also be imported back into RoomSheet.

Requirements

新しい室内スキャンには、RoomPlanに対応したLiDAR搭載iPhoneまたはiPadが必要です。 LiDAR非搭載端末でも、既存のRoomSheetパッケージの読み込み、閲覧、管理、書き出しは利用できます。

Creating a new room scan requires a LiDAR-equipped iPhone or iPad supported by RoomPlan. Devices without LiDAR can still import, view, manage, and export existing RoomSheet packages.

Location / 位置情報

スキャン時に、市町村レベルのおおまかな位置情報と方位を メタデータとして記録することがあります。位置情報の許可は任意で、 拒否しても室内スキャン自体は利用できます。

RoomSheet may record approximate municipality-level location and orientation as scan metadata. Location permission is optional and is not required to create a room scan.

Privacy

データの保存

RoomSheetはユーザーアカウントや独自のクラウドサービスを運営していません。 スキャン、参考写真、生成ファイルは端末内、またはユーザーが明示的に選択した Files等の保存先に保存されます。RoomSheetがスキャンデータを独自サーバーへ 自動送信することはありません。

位置情報と方位

許可された場合、スキャンに市町村レベルのおおまかな位置情報と方位を メタデータとして保存することがあります。位置情報の利用は任意です。

参考写真

RoomSheet内で撮影した参考写真はRoomSheetのスキャンデータとして保存され、 Photosライブラリへ自動保存されません。

Data storage

RoomSheet does not operate a user-account system or its own cloud service. Scans, reference photos, and generated files are stored on the device or in locations explicitly chosen by the user through system file interfaces. RoomSheet does not automatically upload scan data to a RoomSheet-operated server.

Location and orientation

If permission is granted, RoomSheet may store approximate municipality-level location and orientation as scan metadata. Location access is optional.

Reference photos

Reference photos captured in RoomSheet are stored with the RoomSheet scan and are not automatically saved to the Photos library.

Privacyに関する質問も GitHub Issues から送信できます。 Privacy questions can also be submitted through GitHub Issues.
